# Инструкция: как пользоваться агентом

Агент сам находит заказы, оценивает их и присылает подходящие в Telegram.
Вы нажимаете кнопку — он пишет черновик отклика и считает цену. Отклик **отправляете вы**
(копируете текст на платформу), а потом кнопками отмечаете, что было дальше.
Из этих отметок строится вечерний отчёт.

---

## 1. Установка (один раз, ~15 минут)

Нужны: Python 3.12+ и git. Агент должен работать постоянно, поэтому лучше
поставить его на недорогой сервер (VPS) — см. раздел 8. Для пробы подойдёт и ваш компьютер.

**macOS / Linux:**
```bash
git clone https://github.com/piotrgoncharuk/agent.git
cd agent
python3 -m venv .venv
.venv/bin/pip install -e .
cp .env.example .env
```

**Windows (PowerShell):**
```powershell
git clone https://github.com/piotrgoncharuk/agent.git
cd agent
py -m venv .venv
.venv\Scripts\pip install -e .
copy .env.example .env
```
Дальше в инструкции команды `.venv/bin/fa …` на Windows пишутся как `.venv\Scripts\fa …`.

Все настройки хранятся в файле `.env` — откройте его любым текстовым редактором.
Этот файл не попадает в GitHub, ключи остаются только у вас.

## 2. Ключ Claude (для черновиков и профилей)

1. Зайдите на https://console.anthropic.com → **API Keys** → **Create Key**.
2. Пополните баланс в разделе Billing (для начала хватит $10–20).
3. Вставьте ключ в `.env`: `ANTHROPIC_API_KEY=sk-ant-...`

Один черновик отклика стоит порядка нескольких центов. Без ключа агент всё равно
собирает и оценивает заказы — не работают только черновики и профили.

## 3. Telegram-бот

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и логин бота
   (логин должен заканчиваться на `bot`).
2. BotFather пришлёт токен вида `123456:ABC...` — вставьте в `.env`:
   `TELEGRAM_BOT_TOKEN=123456:ABC...`
3. Запустите агента: `.venv/bin/fa run`
4. Найдите своего бота в Telegram и напишите ему `/start`.
   Он ответит: «Ваш chat_id: 123456789».
5. Впишите его в `.env`: `TELEGRAM_CHAT_ID=123456789`
6. Остановите агента (Ctrl+C) и запустите снова: `.venv/bin/fa run`
7. Напишите боту `/help` — должен прийти список команд.

Бот выполняет команды **только из вашего чата**. Остальным он показывает их chat_id и больше ничего не делает.

## 4. Откуда берутся заказы

| Платформа | Как попадают заказы | Что сделать |
|---|---|---|
| Freelancehunt | автоматически, через API | взять API-токен в настройках профиля Freelancehunt → `FREELANCEHUNT_TOKEN=` |
| Freelancer.com | автоматически, через API | токен на developers.freelancer.com → `FREELANCER_TOKEN=` |
| Useme | автоматически, через RSS | вставить ссылки RSS-лент категорий в `config/platforms.yaml` → `useme: feeds:` |
| Upwork, Kolabtree, PeoplePerHour | письма-уведомления → вы пересылаете боту | на платформе сохранить поиск и включить уведомления на почту |
| LinkedIn, агентства, Fiverr | вручную | увидели заказ — переслали боту |

**Как переслать заказ боту** — команда `/add`, платформа, а со следующей строки текст:
```
/add upwork
Biostatistician for mixed model analysis in R
Budget: $600
Longitudinal clinical trial data, need mixed models...
https://www.upwork.com/jobs/~01abc...
```
Первая строка текста считается заголовком. Бюджет и ссылку агент найдёт сам.
Если заказ подходит, бот пришлёт карточку с кнопками. Если нет, скажет, что заказ пропущен, но вернуть его можно одной кнопкой.

## 5. Ежедневная работа

Запущенный `fa run` делает три вещи:
- **каждые 30 минут** собирает заказы с автоматических источников;
- **подходящие** (оценка ≥ 60 из 100, без тревожных признаков) сразу присылает в Telegram;
- **в 20:00** присылает отчёт за день.

Под каждой карточкой — кнопки. Они всегда показывают только возможные следующие шаги:

```
🆕 карточка заказа    →  ✍️ Черновик  |  ⏭ Пропустить
черновик готов        →  ✅ Отправил  |  🔁 Переписать  |  ⏭ Пропустить
отправлен             →  💬 Клиент ответил  |  ❌ Не взяли
клиент ответил        →  🤝 Контракт  |  🗣 Переговоры  |  ❌ Не взяли
контракт              →  📦 Сдал работу
сдал                  →  ⭐ Получил отзыв
```

**Типичный цикл:**
1. Пришла карточка → читаете → **✍️ Черновик**.
2. Через 10–30 секунд приходят два сообщения: сам текст отклика (удобно скопировать)
   и сводка — цена с расчётом, вопросы клиенту, ссылка на заказ.
3. Проверяете текст. Если в нём есть `[квадратные скобки]`, впишите туда свои данные
   (их нет в профиле — см. раздел 7). Вставляете отклик на платформу и отправляете.
4. Жмёте **✅ Отправил**.
5. Клиент ответил → **💬**. Наняли → **🤝 Контракт**. Сумма берётся из черновика.
   Если договорились о другой: `/won 12 450` (заказ #12, $450).
6. Сдали работу → **📦**, получили отзыв → **⭐**.

Отмечайте шаги честно, даже «❌ Не взяли»: на этом считается конверсия по платформам,
и через неделю будет видно, где отклики работают лучше.

## 6. Команды бота

| Команда | Что делает |
|---|---|
| `/jobs` | 10 лучших заказов, ждущих решения (с кнопками) |
| `/job 12` | карточка заказа #12 |
| `/add upwork` + текст | добавить заказ вручную |
| `/won 12 450` | контракт по #12 на $450 (или исправить сумму) |
| `/collect` | собрать заказы прямо сейчас |
| `/report` или `/report 30` | отчёт за 7 (или 30) дней |
| `/help` | справка |

Отчёт показывает:
- сколько заказов собрано и сколько из них подошло;
- отклики, контракты и конверсию (цель 3–5%);
- выручку относительно цели $10 000 к 11 декабря и сколько нужно зарабатывать в день;
- отзывы (цель — 3 к 15 ноября);
- разбивку по платформам.

## 7. Настройка под себя

| Что | Где |
|---|---|
| Ваши данные для откликов и профилей (образование, опыт, публикации, кейсы) | `profiles/master.yaml` |
| Цены услуг (сейчас стоят ориентиры) | `config/services.yaml` → `price_usd` |
| Ключевые слова услуг (en/pl/ru/ua) и тревожные признаки | `config/services.yaml` |
| Порог оценки для уведомлений | `.env` → `SCORE_NOTIFY_THRESHOLD=60` (меньше — больше заказов) |
| Частота сбора, время отчёта, часовой пояс | `.env` → `COLLECT_INTERVAL_MIN`, `REPORT_TIME`, `TIMEZONE` |
| Уточнять оценку через Claude | `.env` → `USE_LLM_SCORING=true` (точнее, но платно) |

После изменения файлов перезапустите агента.

**Тексты профилей для платформ:**
```bash
.venv/bin/fa profile upwork en
.venv/bin/fa profile useme pl
.venv/bin/fa profile freelancehunt ua
```
Выводятся готовые тексты для каждого поля с учётом лимита символов и список навыков (skills).
Сначала заполните `profiles/master.yaml`, иначе в текстах останутся `[плейсхолдеры]`.

## 8. Работа 24/7 на сервере

На компьютере агент работает, только пока открыт терминал и компьютер не спит.
Для постоянной работы подойдёт самый дешёвый VPS (Hetzner, DigitalOcean и т.п., ~$5 в месяц, Ubuntu):

```bash
# на сервере
sudo apt update && sudo apt install -y python3-venv git
git clone https://github.com/piotrgoncharuk/agent.git && cd agent
python3 -m venv .venv && .venv/bin/pip install -e .
nano .env                       # вставить те же ключи, что и локально
# в deploy/freelance-agent.service заменить USER на имя пользователя, затем:
sudo cp deploy/freelance-agent.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now freelance-agent
journalctl -u freelance-agent -f   # смотреть логи (выход — Ctrl+C)
```
Агент сам перезапускается после сбоя или перезагрузки сервера.
**Запускайте его только в одном месте**: два бота с одним токеном мешают друг другу.

**Обновление** после изменений в коде:
```bash
cd agent && git pull && .venv/bin/pip install -e . && sudo systemctl restart freelance-agent
```

## 9. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Бот молчит | Запущен ли `fa run`? Правильный ли `TELEGRAM_CHAT_ID`? Перезапустили ли агента после правки `.env`? |
| «Не получилось: API error 401» | неверный `ANTHROPIC_API_KEY` |
| «… 400 / credit balance» | закончился баланс на console.anthropic.com |
| Карточки не приходят | возможно, просто нет подходящих заказов: проверьте `/collect` и `/report`; попробуйте снизить `SCORE_NOTIFY_THRESHOLD` |
| «⚠️ Ошибки сбора: freelancehunt …» | проверьте токен платформы; остальные источники при этом продолжают работать |
| «… не разрешён» после нажатия кнопки | кнопка устарела (заказ уже на другом этапе) — используйте кнопки из последнего сообщения |

Все данные хранятся в `data/agent.db`. Чтобы сделать резервную копию, достаточно скопировать этот файл.
